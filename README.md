# Rudransh Math Quest v2

A child-safe, offline Android maths adventure personalized for Rudransh (age 7).

## Included
- Number sense and place value
- Addition and subtraction
- Times tables (2, 3, 4, 5 and 10)
- Mixed practice and daily challenge
- Coins, levels, streaks and encouraging feedback
- Read-aloud questions
- PIN-protected parent dashboard (`1111`)
- No ads, sign-in, chat, analytics or internet permission

The APK is built automatically under **Actions → Build Android APK**.
